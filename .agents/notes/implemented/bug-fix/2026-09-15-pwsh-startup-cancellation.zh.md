# Agent Note: 保留受管进程启动期间的 PowerShell 取消状态

Status: implemented

[English](2026-09-15-pwsh-startup-cancellation.md) | 中文

## 问题

Windows 受管子进程提供方可能在启动完成前，以调用方的取消原因拒绝退出结果。PowerShell 前台执行器此前将其视为基础设施错误，导致短超时和提前取消丢失约定的结果标记。

## 决策

执行器仅将与已中止的截止信号原因完全相同的拒绝转换为退出结果为空的执行结果。返回已有的超时或取消标记前，先等待进程清理完成。其他提供方错误仍会抛出。

## 考虑过的替代方案

**增大超时。** 这只会隐藏启动竞态，没有处理较慢主机上的取消。

**转换取消后的所有拒绝。** 这会隐藏与中止同时发生的独立提供方错误。

## 影响

确定性的提供方测试覆盖截止超时、调用方取消、清理等待，以及信号已中止和未中止时的独立错误。真实 PowerShell 执行器与工具集成测试覆盖 Windows 启动路径。工具结果格式和权限判定保持不变。
